# IT System Health Monitor

A Python-based system monitoring tool designed to collect and analyze basic Windows computer performance metrics.

## Project Overview

This project demonstrates foundational IT support skills through a Python script that monitors system resource utilization and identifies potentially high resource usage.

## Features

- Detects operating system and processor information
- Monitors live CPU utilization
- Reports RAM usage and available memory
- Measures disk usage and free storage
- Displays warnings when resource utilization exceeds 90%

## Technologies Used

- Python 3
- psutil library
- Windows PowerShell
- GitHub

## How to Run

1. Install Python 3.
2. Install the required library using `py -m pip install psutil`.
3. Run `py system_health.py` in PowerShell.
